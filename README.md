
# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Дерев’янко Дмитро
- Група: ІН-31-2

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

## Висновки
Під час виконання лабораторної роботи № 6 було опановано базові принципи роботи з сервісом GitHub: створення публічного репозиторію, організацію структури папок навчального проєкту, завантаження файлів баз знань CLIPS (.clp, .txt) через коміти та оформлення документації проєкту мовою Markdown у файлі README.md. Основною особливістю Git стало те, що він не зберігає порожні каталоги, тому для створення кожної папки Lab1–Lab5 спочатку було додано внутрішній файл README.md, після чого завантажено відповідний код експертних систем.
